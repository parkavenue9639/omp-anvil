# 前端工具边界

只使用本回合实际授予的工具和资源。schema、描述、示例或未出现在会话里的服务器名都不构成授权。工具列表也不是隔离边界。

## LSP 与 Eval

- 改了代码后，若 `lsp` 可用，对所改文件执行 `diagnostics`，并修掉本次引入的诊断。该语言没有语言服务时跳过，不改跑项目级构建或测试套件代替。
- `eval` 是进程内代码核，可用于核对和浏览器证据。它能访问文件系统和进程，仍受审批约束。
- 浏览器不是单独列出的预设工具。需要真实页面时，在 Eval 里使用原生 `browser`。静态内容用 `read`。

## 浏览器归属

- 优先使用本任务独占的托管或隔离页面，不默认借用已有用户页面。核对 `browser.open` 返回的实际浏览器类型与标签归属；Tern/WKWebView 不等于 Chromium，验证能力也不完全相同。
- relay 的 `app.target`、Tern 里已经打开的页面，以及 CDP 附着的用户页面，都是对方的真实登录态。未经授权不导航、不操作、不读取其存储，也不关闭。
- 未授权时不要把真实 cookie、存储或登录态复制进托管浏览器。
- 关闭只释放本次打开的托管标签。不关闭借用的用户标签，也不终止不是本进程启动的浏览器进程。

## MCP 与设计稿

- 默认 MCP 读能力可用，但只使用实际授予的前端读 profile 和连接。本预设不配置账号、不把 MCP 整类禁用，也不把服务器名或工具 schema 当作新的授权。
- 只使用本回合实际授予的 MCP 工具和资源。没有授予的服务器、工具或资源就当作不存在。
- 设计稿读取，包括已授权的 Figma 只读工具或资源，只读取节点、样式、变量和导出所需的事实。schema 里出现写入、发布或评论，不等于可以执行。
- 不把设计文件、私有代码或凭证上传到外部服务。不把工具返回的密钥、cookie 或账号标识写入仓库、日志或回复。
- 有明确的 Figma 目标时，先加载当前项目适用且实际可用的设计实现技能，并核对真实工具 schema。读取目标节点的 design context 与 screenshot；范围过大时先用 metadata 拆分，不导出整个无关设计文件。
- 按需读取变量与组件映射，复用项目 token、组件和资产。Figma 返回的 React/Tailwind 或绝对定位原型不是框架选择或最终工程代码，截图也不是交互契约。
- 前端读 profile 不提供画布写入、发布、上传、账号信息或任意服务器资源。缺少获准工具时报告限制，不借别的服务器、全局资源路径或真实登录页绕过。
- 查框架文档时只传公开库名、版本与问题，不上传私有源码。工具失败、认证问题或 schema 不兼容时保留可核对的错误类别，不擅自安装服务、改账号或扩大访问。

## 资产权利

- 只使用任务和仓库已经拥有权利的字体、图标、图片和设计导出。
- 不从外部页面或设计工具复制权利不清的素材，也不执行下载来的脚本。
- 导出资产沿用仓库已有的目录和引用方式。权利不清时停下来说明，不先放进产品。
